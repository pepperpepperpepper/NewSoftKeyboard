# UI Settings Inventory

This table is a **best-effort inventory** of user-facing settings surfaces, based on preference XML screens plus curated theme customization entries.

Tap-path click map: `docs/settings-clickpaths.md`.

Notes:

- Keys starting with `nav:` are **actions/navigation** (not persistent settings).
- Some rows may be legacy/hidden screens that are still present in the navigation graph; treat the **Screen path** as the source of truth.
- Some `@string/...` defaults/keys may appear unresolved when the resource is defined in a dependent module.

## Hidden / internal preference keys (not user-facing settings)

These keys exist in `ime/app/src/main/res/values/settings_keys_dont_translate.xml` and are read/written by code, but are not currently exposed as direct settings rows in the primary settings UI.

- `HistoryQuickTextKey_encoded_history_key` (`settings_key_quick_text_history`): quick-text ranking/history store; may contain user-entered snippets. **Risk:** medium (local retention).
- `settings_key_smiley_icon_on_smileys_key`: internal UI flag (observed in `ImeRxPrefs`). **Risk:** low.
- `settings_key_use_16_keys_symbols_keyboards`: internal/legacy symbols layout toggle (wired in `KeyboardSwitcherPrefsBinder`). **Risk:** low.
- `settings_key_persistent_layout_per_package_id_mapping`: per-app layout memory data store (package IDs ↔ layout IDs). **Risk:** medium (local app list retention).
- `settings_key_custom_keyboards_enabled_ids`: internal custom keyboards allow-list store. **Risk:** low.
- `settings_key_custom_keyboards_generation`: internal cache/versioning key for custom keyboards. **Risk:** low.
- `settings_key_custom_keyboards_pack_theme_mapping`: internal mapping of custom keyboard packs to theme IDs. **Risk:** low.
- `settings_key_support_keyboard_type_state_row_type_2` / `3` / `4` / `5`: internal row-mode enablement flags. **Risk:** low.
- `settings_key_show_slide_for_gesture_back_word_counter`: internal gesture-typing UI/debug flag. **Risk:** low.
- `settings_key_openai_enabled`: legacy migration flag for the dictation backend selector (see `SpeechToTextSettingsFragment`). **Risk:** low.
- `settings_key_openai_copy_destination`: appears unused in current sources; document or remove if it becomes active. **Risk:** unknown.
