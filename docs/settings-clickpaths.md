# UI Settings Click Map

This is a **tap-path map** for adjustable features reachable from the in-app **Settings home** screen.

## Conventions

- **Starting point:** Settings home (the first screen after opening Settings).
- **Clicks:** number of taps from Settings home to reach/toggle the item (does not include opening Settings itself).
- **Location:** a non-clickable section header within the current screen (for orientation only).
- Some rows are conditional (only appear when prerequisites are met).

Best-effort source inventory: `docs/user-stories-settings-inventory.md`.
